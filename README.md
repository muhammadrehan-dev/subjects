## Contributing
Contributions are welcome — please help keep this library useful for students:

- Preferred workflow: Fork the repository, add or update files in the appropriate folder, then open a Pull Request with a short description of your changes.
- If you have many files to share (e.g., a full drive or large attachments), please contact the folder maintainer first (see Contact / Maintainers) before uploading to avoid duplication.
- Keep filenames and folder structure clear and consistent (e.g., "<Batch> <Subject>/<Semester>/<Instructor>/").
